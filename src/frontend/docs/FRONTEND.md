# 前端架构与功能边界

React 19 + TypeScript + Vite，保留现有依赖与锁文件，无额外状态库或动画库。Hash路由便于静态部署；Context管理首屏快照、通知和会话重置，页面懒加载。深海蓝/灰金视觉、抽屉导航、全屏星图与本地船只/灯塔/回声插画继续沿用。[美术资产](ART-ASSETS.md)包含提示词和来源；CSS/SVG光照、摄像机推进、划船视频与流星无需外部服务。

## 交互和持久化

全站侧栏默认隐藏，左上角三横线悬停临时展开、点击固定，Escape/遮罩/切换路由关闭，带滑入滑出与焦点隔离。院校星图占满视口，筛选收于浮层。选择学校后从当前船只位置划至目标并前往该校回声，支持取消/跳过。系统prefers-reduced-motion停用主要动画。无家长模式、日夜开关或背景音。

真实数据经HTTP读取，首屏只是一页快照；学校/帖子/证据按ID取，列表游标分页。HTTP风险仅展示后端结果，未知显示待确认。校园生活查询不强制成绩。推荐只在显式点击后创建，离页/停止监听不取消任务；任务状态、版本及证据可复核，SSE与快照交叉验证。

会话Cookie由后端处理；401与切换账号清空个人Context、聊天和比较/停靠状态，旧epoch请求不能覆盖新账号。任务ID/游标按用户sessionStorage保存。Mock的个人业务数据按账号分区，仅为演示；注册凭据/密码哈希/音频和证明文件只驻内存。刷新后新注册账号不可重新验证密码，需重新走申请或使用公开夹具。

表单有标签；弹窗焦点约束、键盘路径、星图列表替代、静态减少动效模式已提供。新增审核/任务表单在窄屏改为单列，但本轮浏览器验收为桌面，手机实机与完整可访问性认证仍待验证。

## 实现边界

具体F01–F12迁移见 [TECHNICAL-ALIGNMENT](TECHNICAL-ALIGNMENT.md)。前端提供可运行Mock和HTTP契约；HTTP 模式已连接真实 FastAPI、Worker 和 PostgreSQL。领航员普通问答已接入 OpenAI 兼容模型，只检索已发布的招生单位和用户画像，SSE 返回工具状态、证据和文本增量；聊天中明确提到与当前画像不同的省份/分数/位次/选科时，会显示待确认卡片，用户确认后才生成新的画像版本。画像保存后可通过“修改考生档案”再次编辑。向量检索、工具型 Agent、跨用户记忆尚未实现。考生画像将省份、年份、分数、位次和同意作为推荐必需项，选科/城市/专业/预算等可选；画像表单提供城市、专业和院校的模糊搜索建议，缺少可选信息时结果页展示三种策略分支及各自利弊，并提示补充画像。官方采集、权限审计、任务队列和自动抓取由后端实现；省份表单与Mock主要演示浙江三选科，不能冒充全国正式填报工具，志愿导出是草案，不是省考试院导入格式。
