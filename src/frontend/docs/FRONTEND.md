# 前端实现说明

## 技术选型

选择React + TypeScript + Vite单页应用。项目后端已有FastAPI方向，页面以登录后交互、数据探索和草案编排为主，不依赖服务端渲染；无需额外搭建Node业务服务。TypeScript让Profile、School、Post、Trust、Plan、SSE事件类型在页面和访问层保持一致。Vite负责开发代理、构建和动态模块拆分。

状态使用React Context + Hooks；目前业务规模无需额外状态库。Hash路由不依赖服务器rewrite。lucide-react提供一致的线性图标；星图、画像星座和曲线采用DOM/SVG，示例节点很少，交互与键盘可访问性优先，无需引入WebGL或重型图表库。大量院校应在服务端分页后换成虚拟列表或分级Canvas渲染。

首屏加载首页和星图；内容、规划、账号和对话模块按需加载。所有业务写入经过`api`，页面不直接构造FastAPI请求。mock与http通过构建环境变量切换，HTTP错误可见且不会回退虚构数据。

## 设计方向

深海军蓝为主画布，暖金为重点行动色，青绿 / 珊瑚 / 浅蓝配合 ● / ▲ / ■ 表达稳 / 冲 / 保。来信使用米白纸张，宋体标题、邮戳与克制的纹理构成真人体验层。官方来源以蓝、体验以暖色、推断以紫区分，同时提供文本标签，不仅依赖颜色。

全站默认收起侧栏，内容不预留侧栏宽度。左上角三横线按钮支持悬停临时展开、点击固定展开，点击遮罩、再次点击按钮或按 Escape 收起；路由切换时自动关闭。隐藏导航使用 inert，避免焦点进入屏幕外控件。手机也使用相同的抽屉入口。院校星图独占视口，筛选/列表收纳在右上角面板中。星图保留列表模式，画像保留完整表单。模态使用原生dialog焦点约束，对话支持Escape与焦点循环；表单均有标签，状态通知使用role=status。

默认尊重`prefers-reduced-motion`。已移除家长模式及原太阳/月亮图标按钮。船与人物使用确定周期的轻微漂浮动画，抽屉导航使用滑入滑出与遮罩淡入淡出；系统减少动效设置会停用这些动画。没有背景音、强闪烁或动画粒子依赖。图案使用本地CSS/SVG与生成的透明PNG；宋体优先Noto Serif SC（Google Fonts可用时），断网回退系统宋体，不影响功能。

没有宣称完成WCAG认证：键盘路径、列表替代、焦点和减少动效已经实现，正式上线仍需做完整的对比度、屏幕阅读器、低端机与真实家长可用性测试。

## 交互与持久化

- 演示：业务快照在`night-voyage-demo-v1`；对比ID在`nv-compare`；已停用旧的`nv-large`与`nv-reduce`模式记录。演示是单浏览器开发状态，不能代替多账号隔离。
- 真实模式：画像、收藏、方案、帖子、认证均经后端；对比选项与界面偏好仍保存在浏览器；聊天仅内存存在，不自动长期保存。
- 登录会话不保存在localStorage；服务端Cookie处理身份。审核角色由后端返回，前端守卫只改善体验。
- 方案更新采用version乐观锁；前端写入后使用服务端返回的全新Plan。冲突时保留当前视图并要求刷新，不盲目重试覆盖。
- 卡片收藏可取消；加入志愿后显示勾选；工作台提供拖放和上下按钮两种排序方式。
- CSV浏览器导出，打印样式可通过系统打印对话框保存PDF；不声称生成官方填报格式。
- 来信投稿进入pending；对公众只展示published。自己的未公开稿件可预览，评分申诉不需要认证，但投票需要认证身份。
- 回声页使用 `/echoes/{schoolId}`，只显示该校公开内容和学校信息；本校筛选逻辑在 `campusPosts`。`nv-echo-school` 在localStorage记住最近查看的学校，投稿时预选该校；`nv-atlas-dock` 在sessionStorage记录本标签页的星图停靠学校。
- 星图选中学校后显示右下角入口。航行动画沿当前显示坐标至目标星体的曲线移动，结合静音、循环、内联播放的VP8/WebM划船动作。视频未能播放时使用同源逐帧PNG动画；取消或路由卸载会取消位置动画，避免延迟跳转。跳过会立即抵达；减少动效模式直接进入回声页。
- `campus-night.png` 是生成的仰望星空插画，流星由CSS叠加短时移动与金色拖尾，每颗的周期错开，提供暂停按钮。插画和视频随项目部署，离线版本以data URL内嵌。

本次覆盖建议文档中的启航、档案、领航员、星图 / 列表、院校档案、回声广场、帖子与可信度报告、航线、对比、工作台、认证投稿、基础审核与我的页面。所有主要按钮有对应交互与访问层调用；当前提供可供业务评审的演示和可替换的HTTP对接。
