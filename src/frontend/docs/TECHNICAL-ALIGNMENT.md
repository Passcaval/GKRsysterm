## 数据边界

浏览器Mock模拟纵向流程，不提供真实安全保障。申请/密码验证资料/音频/证明文件只保留当前JS内存，刷新会消失；合成任务/画像/记忆等写本地存储并按账号命名空间区分。真实HTTP模式不在localStorage保存会话、申请查询凭据或原件。个人案例共享与本次画像使用授权分开，默认关闭且可撤回。

本版UI和契约已覆盖上述迁移点，尚无后端实现，不能据此宣称生产注册、审核、推荐或安全验收完成。多省复杂填报规则、真实校准概率、全量院校地图性能、运营举报处理等仍需后端和后续产品开发。核心交付与验证见 [API](../../../docs/contracts/API.md) 和 [VALIDATION](VALIDATION.md)。
