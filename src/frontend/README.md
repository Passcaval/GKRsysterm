# 夜航 · Night Voyage

高考志愿查询与推荐系统前端，React 19 + TypeScript + Vite。与 Python / FastAPI / PostgreSQL 服务分离部署。

工程根目录为仓库中的 `src/frontend/`，下方命令均在此目录执行。

M0–M1 真实 FastAPI/PostgreSQL 后端已按本前端 v0.4 对接，按[后端说明](../backend/README.md)启动，再设置 `VITE_API_MODE=http` 使用原有统一登录页。已支持的工作流及后续阶段限制见[实际接口评估](../../docs/contracts/BACKEND.md)。演示账号不能登录真实后端；真实模式邮箱格式由后端校验并返回重新输入提示。

领航员内可直接填写省份、年份、位次和三门选科生成推荐。分数及地域、专业、院校偏好均可后补；更新后使用新画像版本重新推荐，旧记录保留。自然语言提取与具体 API 字段见[领航员对接说明](../../docs/contracts/NAVIGATOR.md)。

**离线预览：安装依赖后运行 `pnpm run standalone`，再双击生成的 `夜航-交互预览.html`。** 页面、素材、样式和脚本打包为单文件，固定使用演示模式；查看生成文件时无需启动服务，离线预览使用系统字体。该文件属于可复现的构建产物，不提交到仓库。

## 启动

需要 Node.js 22.18+（当前验证为 24）、pnpm 11.25.0（与 packageManager 一致）。在本目录运行：

```powershell
pnpm install --frozen-lockfile
pnpm run dev
```

打开 http://127.0.0.1:5173 。默认 `mock` 演示模式，完全不需要后端。首次安装后的版本以 `pnpm-lock.yaml` 为准。

```powershell
pnpm run contract:check
pnpm run test
pnpm run build
pnpm run preview
pnpm run standalone
```

若本机 pnpm 的启动包装器有问题，可直接执行等价命令：

```powershell
node --experimental-strip-types --test ../../test/frontend/*.test.ts
node node_modules/typescript/bin/tsc -b
node node_modules/vite/bin/vite.js build
node node_modules/vite/bin/vite.js --host 127.0.0.1
```

## 切换真实后端

将 `.env.example` 复制为 `.env.local`，设置后重启开发服务：

```dotenv
VITE_API_MODE=http
VITE_API_BASE_URL=/api/v1
```

开发代理已将 `/api` 转发到 `http://127.0.0.1:8000`。生产可把 `dist/` 部署到静态服务器，并反向代理 `/api` 到 FastAPI。使用 Hash 路由，刷新子页面无需额外的 SPA rewrite。正式模式不会把后端错误静默替换成演示数据。生产未配置模式时默认HTTP，开发默认Mock；非法模式值直接报错。对接需采用v0.4 snake_case DTO、request_id信封及对应状态码，旧v0.1服务不能直接混用。

## 页面与操作

2026-10-21 星图布局修复：院校按可用屏幕宽度分散排布，数量较多时滑动浏览；坐标仅用于探索，不代表位次或录取风险。保留分页、筛选、缩放、船只停靠和划船进入回声广场，取消院校简称圆章。PC、平板、手机竖屏与横屏检查范围见[验证记录](docs/VALIDATION.md)。

v0.2：全站改为左上角三横线抽屉导航；启航页加入内置图像生成制作的船上人物与灯塔，金色光束照向手持星图，点击星图通过镜头推进进入全屏院校星图。星图以俯视船只表示个人位置，星体带局部金色渐变光晕。素材位置与完整提示词见 [美术资产说明](docs/ART-ASSETS.md)。

v0.4：按新增技术方案接入申请审批、画像版本、异步推荐补问与SSE恢复、推荐反馈/记忆、独立案例共享、招生单位及详情分页；保留唯一登录页，完整迁移见 [对齐记录](docs/TECHNICAL-ALIGNMENT.md)。

v0.3：回声广场按院校独立展示。星图选中院校后点击右下角「前往回声广场」，俯视人物播放划船动作视频，沿航线抵达该校；支持跳过和取消，返回星图会保留本次停靠位置。回声页加入仰望星空插画、带拖尾的流星、院校信息及本校投稿入口。视频为生成逐帧素材编码的本地 WebM，无需外部视频服务。

统一登录页为 `/#/login`，只填写“邮箱或用户 ID”和密码，不选择身份。普通账号进入“我的”，内容审核员进入内容审核台，拥有注册审核权限的管理员进入注册审核台；普通账号不显示管理入口，直接访问也不能加载审核队列。HTTP 模式下身份来自后端响应，不通过登录请求提交。

## 演示范围

全部院校位次、学费、帖子、评分和工具结果均为虚构演示，不可用于填报。演示只涵盖浙江三门选考科目的场景，其他省份推荐会明确提示尚未覆盖。注册申请/密码验证资料/语音与学校证明只保留当前JS运行内存，刷新或热更新后清空；学校证明元数据和合成任务可持久化。Mock不可用于真实敏感资料。

目前交付的是可运行的前端与拟定的接口契约。工作区没有现成后端实现，所以真实数据采集、模型、检索、认证审核和推荐校准仍由后端团队实现。详细界限和双方待确认项见文档。
